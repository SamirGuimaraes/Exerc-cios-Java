# Exercícios de Programação em Java

**Disciplina:** Linguagem de Programação II (LP2)

## Descrição

Este repositório contém uma coleção de exercícios práticos sobre os principais conceitos de Programação Orientada a Objetos (POO) em Java. Os exercícios abordam os fundamentos da linguagem, como **herança**, **polimorfismo**, **encapsulamento**, **sobrecarga de métodos** e **construtores**. Cada exercício foi desenvolvido para ajudar os alunos a entender e aplicar esses conceitos de maneira clara e objetiva.

## Abordando os principais assuntos de POO

### 1. Herança
- **Objetivo:** Demonstrar a criação de classes base e derivadas.
- **Descrição:** A herança permite que uma classe herde os atributos e métodos de outra, promovendo reutilização de código e a criação de hierarquias de classes.


### 2. Polimorfismo
- **Objetivo:** Explorar o conceito de polimorfismo, que permite que um método tenha comportamentos diferentes dependendo do objeto que o invoca.
- **Descrição:** O polimorfismo pode ser aplicado através de sobrecarga e sobrescrita de métodos. Com ele, o mesmo nome de método pode ser usado para diferentes implementações, dependendo do contexto.


### 3. Encapsulamento
- **Objetivo:** Ensinar como esconder a implementação interna de uma classe e expor apenas os métodos necessários para interagir com ela.
- **Descrição:** O encapsulamento é alcançado através de modificadores de acesso como `private`, `protected` e `public`. Isso permite proteger o estado interno da classe, garantindo que o acesso e a modificação dos atributos sejam feitos apenas de maneira controlada.


### 4. Sobrecarga de Métodos
- **Objetivo:** Explorar como o mesmo nome de método pode ser usado para diferentes tipos de parâmetros.
- **Descrição:** A sobrecarga permite que métodos com o mesmo nome sejam definidos em uma classe, desde que tenham diferentes listas de parâmetros.

### 5. Construtores
- **Objetivo:** Abordar o conceito de construtores, que são utilizados para inicializar objetos.
- **Descrição:** Construtores podem ser definidos para garantir que os objetos sejam criados com valores iniciais válidos. Além disso, o conceito de construtores padrão e parametrizados será explorado.
